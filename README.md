# Clinical Guidelines RAG Assistant

A free, fully local Retrieval-Augmented Generation (RAG) system that answers questions
from public NICE clinical guidelines and always shows the exact passage it used.

(The full README is written in Phase 10.)

## Note on the source content

Guideline text is published by NICE (the UK National Institute for Health and Care
Excellence). It is used here for a **personal, non-commercial educational project**.
Anyone reusing this project or its data should check
[NICE's reuse terms](https://www.nice.org.uk/re-using-our-content) first.
Downloads respect `robots.txt`, use a descriptive User-Agent, wait at least 2 seconds
between requests, and are cached locally so each page is fetched only once.
